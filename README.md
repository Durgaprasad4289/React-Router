# 🚀 React Router Demo

A simple and modern React application built using React + Vite with React Router for seamless page navigation.

---

## 🌐 Live Demo

👉 [View Project](https://durgaprasadcodes.github.io/React-Router/)

---

## ✨ Features

- ⚛️ React 19 + Vite
- 🔀 React Router DOM Navigation
- 📄 Multiple Pages & Dynamic Routes
- 🛍️ Product Listing & Product Details
- 🚀 GitHub Pages Deployment
- 📱 Responsive UI
- ⚡ Fast Development with Vite

---

## 🛠️ Tech Stack

- React
- Vite
- React Router DOM
- JavaScript
- CSS
